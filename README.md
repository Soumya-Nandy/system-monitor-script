# Linux System Monitor Script

A lightweight, automated Bash script designed to monitor core Linux system metrics (Disk, Memory, and CPU usage).

## Features
- Captures real-time storage disk usage.
- Evaluates memory metrics (Used vs. Free RAM).
- Outputs active CPU load percentage.

## How to Run
1. Clone the repository.
2. Grant execution permissions: `chmod +x monitor.sh`
3. Execute the script: `./monitor.sh`
